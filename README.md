# SoftGrowTech_StudentGradeCalculator
📌 Description

This project is a Student Grade Calculator developed in C++ that calculates a student’s total marks, average marks, final grade, and subject-wise grades efficiently. The program allows users to enter the student name, number of subjects, and marks for each subject with proper input validation to ensure accurate data entry.

The system uses functions and dynamic memory allocation to manage and process marks effectively while demonstrating core programming concepts such as arrays, loops, conditional statements, functions, and modular programming in C++.

Additionally, the program includes validation checks to prevent negative values for subjects and marks, improving reliability and user experience. It follows a simple console-based interface for easy interaction and understanding. This project helped strengthen understanding of problem-solving, data processing, and memory management concepts in C++.
